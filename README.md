# AutoPoker
○プログラムの使い方と大まかな動き
・プログラムの使い方
実際のカードを配られることを考え、人とCPUで戦えるように変更した。
quot_HvsC.exeを開いていただければ、quotが始まる。quot_HvsC.pyがそのソースコードとなっている。

・プログラムの大まかな動き
1. 山札のリストを作成、およびシャッフル
2. それぞれの手札と確定場所、場、捨て場のリストを作成 (以下6つのリストと略す)
3. それぞれの手札、場に山札から3枚ずつカードが配られる
4. 6つのリストの現在、保持しているカードのマークと数字を表示
※リストとは、要素(数字、文字)を含んだ配列のことである
5. 以下 player が交互に操作を行う
6. CPU1は、人の手で指示に従い、数字を入力することで動かす
7. 手札が5枚を超えないように場から1から3枚必要なカードを選択
8. 6つのリストの保持しているカードのマークと数字を表示
9. 手札のから役の確定場所に移動もしくは手札から1枚カードを捨て札に移動
(手札のカードが5枚でないと役の確定は行えない )
10. 6つのリストの保持しているカードのマークと数字を表示
11. 山札なくなっていないとき、playerを交代し、5に戻る
12. 山札がなくなったときにゲームが終了それぞれの確定場所の役、合計点が表示され勝者が決まる
